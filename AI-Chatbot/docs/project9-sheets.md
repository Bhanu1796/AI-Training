# Project 9 — CSV / Google Sheets Query Agent

Ask natural-language questions about any tabular data source: an uploaded CSV/Excel file or a live Google Sheet. Answers are generated by a LangChain Pandas DataFrame agent backed by the configured LLM.

---

## UX Flows

### Flow A — Google Sheets
1. User clicks the **Table2** icon in the InputBar toolbar.
2. An inline violet pill appears above the textarea with a text input field.
3. User pastes the full Google Sheets URL (e.g. `https://docs.google.com/spreadsheets/d/…/edit`) **or** the bare spreadsheet ID.
4. The URL is parsed client-side; only the ID is sent to the backend.
5. User types a question and submits. The thread enters **Spreadsheet mode**.
6. All subsequent questions in the thread are routed through `POST /api/sheets/query`.
7. A violet **Spreadsheet mode** banner appears above the InputBar. Click **✕** to exit.

### Flow B — CSV / Excel File
1. User attaches a `.csv`, `.xlsx`, or `.xls` file via the paperclip.
2. The file is uploaded as usual. The server stores it on disk.
3. ChatPage detects the data file type in the upload response.
4. The thread's `dataFileIds` map is updated with the uploaded file ID; **Data file mode** activates automatically.
5. User types a question and submits — routed through `POST /api/sheets/query-file`.
6. A violet **Data file mode** banner shows the filename above the InputBar. Click **✕** to exit.

## Backend Architecture

```
POST /api/sheets/query
  └─ SheetsQueryRequest { spreadsheet_id, question, thread_id }
  └─ query_spreadsheet()
       ├─ _get_gspread_client()      — loads Google service account credentials
       ├─ gspread.open_by_key()      — fetches sheet1 data
       ├─ pd.DataFrame()             — converts records to DataFrame
       ├─ asyncio.to_thread(         — keeps FastAPI event loop unblocked
       │    _run_pandas_agent, df, question, user_email
       │  )
       ├─ save_message(user)         — persists question to DB
       └─ save_message(assistant)    — persists answer to DB

POST /api/sheets/query-file
  └─ SheetsFileQueryRequest { file_id, question, thread_id }
  └─ query_dataframe_file()
       ├─ SELECT UploadedFile WHERE id=file_id AND user_id=user_id
       ├─ pd.read_csv() or pd.read_excel()
       ├─ asyncio.to_thread(_run_pandas_agent, ...)
       ├─ save_message(user)
       └─ save_message(assistant)
```

---

## Environment Variables

| Variable | Required | Description |
|---|---|---|
| `GOOGLE_SERVICE_ACCOUNT_JSON` | For Flow A only | JSON string of a Google service account credentials file. The account must have **Viewer** access on the target spreadsheet. |

CSV/Excel queries (Flow B) have **no additional environment requirements** beyond the app database.

---

## Supported File Formats

| Extension | MIME type | Read method |
|---|---|---|
| `.csv` | `text/csv`, `text/plain` | `pd.read_csv()` |
| `.xlsx` | `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` | `pd.read_excel()` |
| `.xls` | `application/vnd.ms-excel` | `pd.read_excel()` |

---

## Frontend State

| State | Type | Purpose |
|---|---|---|
| `sheetsThreadIds` | `Set<string>` | Threads with active Google Sheets mode |
| `spreadsheetIds` | `Record<string, string>` | Spreadsheet ID per thread |
| `dataFileIds` | `Record<string, string>` | Uploaded file ID per thread (CSV/Excel) |
| `dataFileNames` | `Record<string, string>` | Original filename for the banner label |
| `isDataQuerying` | `boolean` | Loading state while agent runs |
